# Sheltie — Post-v1 roadmap

Work after M8, kept here so it isn't lost; not part of the v1 milestones.

What comes after M8, in three tracks.

**Product (v2 backlog)**

- [ ] BSP adapter (sbt, Mill, Bazel, Gradle via plugin)
- [ ] Maven adapter (class-signature hashing)
- [ ] Adapters for Go, Python and Nx/JS monorepos
- [ ] GitLab and Bitbucket support
- [ ] Cross-repo atomic changes (changes that must land together)
- [ ] Learned risk model trained on real merge history

**Business (hosted / enterprise layer)**

- [ ] Hosted multi-tenant control plane
- [ ] Billing (per landed PR or per agent)
- [ ] SSO and audit logs
- [ ] Org-wide queues and policy
- [ ] Analytics dashboard (throughput, tiers, footprint-miss, CI cost)

**Adoption**

- [ ] Recruit 3–5 design-partner teams running agent fleets
- [ ] Publish the public benchmark from the demo repositories
- [ ] Launch blog post on softberries.dev
- [ ] Hacker News / community launch
- [ ] Conference talk
