# Social card

`social.html` is the source of `site/assets/social.png` (1200×630, the image shown when sheltie.dev
is shared). To regenerate it, copy `site/assets/logo-512.png` and `site/assets/fonts/Geist-Variable.woff2`
next to it, open it in a browser at a 1200×630 viewport and save a screenshot as
`site/assets/social.png`.
